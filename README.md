# TBELL EDM images

메일(EDM) 본문에서 불러 쓰는 이미지 전용 **공개** 저장소입니다. 메일 원본과 작업 문서는 비공개 저장소 `TBELL-ref/edms`에 있습니다.

## 주소 형식

```
https://raw.githubusercontent.com/TBELL-ref/img/main/<경로>
```

예: `https://raw.githubusercontent.com/TBELL-ref/img/main/bestcon2026-talk/v0.8/01-tgen.png`

## 폴더

- `common/`: 여러 메일이 함께 쓰는 이미지 (로고 등)
- `<캠페인>/<버전>/`: 캠페인 · 버전별 이미지. 폴더 이름은 `edms` 저장소와 같습니다.

## 규칙

- **이미 발송한 메일의 이미지는 옮기거나 지우거나 덮어쓰지 않습니다.** 받은 메일함의 메일이 계속 이 주소를 불러옵니다.
- 이미지를 고치면 새 버전 폴더(예: `v0.9/`)에 올립니다.
- 공개 저장소이므로 발송 전 이미지(미공개 정보가 담긴 것)는 올리지 않습니다.
